# Test samples

Small media used by the model manager's **Test** button to run a real inference with each installed model:

- `face-sample.jpg` — photo with one face (NASA astronaut portrait from scikit-image, public domain).
- `speech-sample.wav` — 16 kHz mono English sentence synthesized with eSpeak NG.
- `text-sample.png` — rendered Arabic and English text for OCR.

Nothing here is ever uploaded anywhere.
